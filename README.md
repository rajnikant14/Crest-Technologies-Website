# Crest Technologies — Marketing Website

Multi-page marketing site for Crest Technologies (www.crest-technologies.com):
embedded systems engineering and IEC 62443 IACS cybersecurity compliance for
rail, aerospace and industrial OT, plus Private Equity services, GCC/BOT
advisory, and product ventures (TMUA.AI, Digital Product Passport with GreenX).

Built with **Next.js (App Router) + TypeScript + Tailwind CSS v4**. All
marketing pages are statically generated.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build (static)
```

## Editing content — no component changes needed

All page copy lives in data files. Edit these and the pages update:

| File | Drives |
|---|---|
| `content/services.ts` | The eight service pages + the Digital Product Passport page (scope, audience, capabilities, stats, delivery stages, outcomes, standards) |
| `content/industries.ts` | Industry pages — Manufacturing group (Rail, Aerospace, Industrial, Automotive) plus Government & Public Sector, Banking & Retail, Oil & Gas |
| `content/private-equity.ts` | PE page: deal-lifecycle strip and the three offers |
| `content/company.ts` | Leadership profiles (with stats), Meet-the-Team profiles, certifications, "why we exist", careers roles |
| `lib/site.ts` | Company name, offices/addresses, email, navigation, venture URLs |

### Add / remove leadership and team profiles

Edit the `leadership` array (About page) or the `team` array (Meet the Team
page) in `content/company.ts`. Each entry needs `name`, `role`, `location`,
`bio`; `photo` (path under `/public`), `linkedin` and — for leadership —
`stats` are optional. Delete an entry to remove the card; duplicate one to add
a person. Until a photo is set, the card shows initials.

### Logo assets

The brand logo lives in `logo/Updated_LOGO.png` (source). Web-ready versions
in `/public` (`logo-full.png`, `logo-mark.png`) and the favicon
(`app/icon.png`) are generated by `node scripts/process-logo.mjs` — re-run it
if the source logo changes.

### Open roles on the Careers page

Edit `careersIntro.openRoles` in `content/company.ts`. "Apply now" opens a
pre-addressed email to `info@crest-technologies.com`.

## Contact form

`components/ContactForm.tsx` posts to Formspree (no backend required):

1. Create a form at [formspree.io](https://formspree.io) (free tier is fine).
2. Replace `REPLACE_WITH_FORM_ID` in the `FORM_ENDPOINT` constant.

Until configured, a failed submission shows a fallback message pointing to the
direct email address, so nothing is silently lost.

## SEO

- Per-page metadata and OpenGraph tags (`app/layout.tsx` + each page)
- Generated OG image: `app/opengraph-image.tsx`
- `app/sitemap.ts` → `/sitemap.xml`, `app/robots.ts` → `/robots.txt`
- Canonical domain is set in `lib/site.ts` (`site.url`); canonical `<link>`
  tags are emitted on every page
- **See [SEO.md](SEO.md)** for domain-variation handling and the Google
  Search Console setup & usage guide

## Design system

Tokens are defined in `app/globals.css` under `@theme`: deep ink/navy base
(`ink-*`), steel-grey neutrals (`steel-*`), restrained brass accent
(`brass-*`), and a signal-teal (`signal-*`) reserved for the sustainability /
DPP context. Type: Archivo (display, semi-expanded), IBM Plex Sans (body),
IBM Plex Mono (spec labels). Focus states are visible; animation respects
`prefers-reduced-motion`.

## Deploy

**Vercel:** import the repo, framework auto-detected, no configuration needed.
Set the production domain to `www.crest-technologies.com`.

**Static hosting:** the site is fully static apart from the generated OG
image route; on Vercel/Node hosting everything works as-is.
